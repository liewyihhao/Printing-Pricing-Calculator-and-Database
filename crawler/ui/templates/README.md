# Product templates

Drop your **own, rights-cleared** print-ready template files here, one folder per product slug.
The per-product landing pages (`ui/products/<slug>.html`, generated by
`python -m app.build_product_pages`) automatically list whatever files are present in the
matching folder; if a folder is empty/absent, the page shows a "templates coming soon" note.

```
ui/templates/
  business-card/
    business-card-90x54-bleed.pdf
    business-card.ai
  greeting-card-litho/
    ...
```

- Folder name = the product's slug (lowercase, hyphenated — e.g. "Business Card" → `business-card`,
  "Greeting Card — Litho" → `greeting-card-litho`). Run the generator once and check
  `ui/products/index.html` for the exact slug of each product.
- Do **not** place third-party (e.g. Excard) copyrighted templates here unless you have the right
  to distribute them. Re-hosting a supplier's artwork/template files can be copyright infringement.
- Any file type works (PDF, AI, PSD, ZIP…); the page shows the filename and size and serves it as a
  download.
