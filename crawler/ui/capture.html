printoka / Market Scan

Capture a fresh market snapshot

Each capture downloads one <product>_options.json. Collect them in a folder, then run the change watcher to see what's new.

1 · Install the capture button (once)

Drag this to your bookmarks bar. (Browsers block dragging into a frame — if needed, right-click → add bookmark, and paste the link as the URL.)

📸 Capture this product
2 · Open each product and click the button

Open a page (wait for the price panel to load), then click the bookmark. It downloads that product's snapshot. (allow pop-ups).

3 · Diff against the baseline

Move the downloaded files into a folder (e.g. output/v4_options_NEW/), then:

python -m app.excard_watch output/v4_options output/v4_options_NEW --json output/change_report.json

Review the report on the Market Watch page. If the changes are real, replace the baseline folder with the new one.
